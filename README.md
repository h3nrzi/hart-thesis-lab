# آزمایشگاه رهگیری تحلیل‌های بازار

این مخزن برای **ثبت مستند و بدون سوگیری تحلیل‌های منتشرشده در تریدینگ‌ویو**، پیگیری اصلاحات تحلیلگر و مقایسه سناریوها با حرکت واقعی بازار طراحی شده است.

> **وضعیت پروژه: زیرساخت آماده‌سازی می‌شود؛ هیچ تحلیلی هنوز ثبت یا بررسی نشده است.**

## هدف

برای هر ایده یک پرونده مستقل می‌سازیم و چهار نوع اطلاعات را از هم جدا نگه می‌داریم:

۱. **بیان خود تحلیلگر:** فرضیه، شروط، سطوح و زمان انتشار؛ تنها با ذکر منبع.
۲. **به‌روزرسانی‌های تحلیلگر:** هر تغییر به‌صورت یک رویداد تازه؛ بدون بازنویسی پیش‌بینی اولیه.
۳. **برداشت مستقل:** توضیح و نقد آموزشی با برچسب روشن «برداشت ما».
۴. **مشاهده بازار و نتیجه:** تنها با داده و تاریخ قابل‌بررسی؛ جدا از تعداد پسندها یا نظرات.

## قاعده طلایی

**هیچ پیش‌بینیِ قدیمی بعد از معلوم شدن نتیجه ویرایش نمی‌شود.** خطاها و اصلاحات باید با زمان ثبت و منبع در رویداد جدید اضافه شوند. «تحلیل درست» و «معامله سودده» یک چیز نیستند.

این پروژه صرفاً برای آموزش و پژوهش است و توصیه سرمایه‌گذاری یا سیگنال معامله محسوب نمی‌شود.
