# الگوهای آماده

برای هر ایده، نسخه‌ای مستقل از الگوهای زیر تهیه می‌شود:

- [تحلیل اولیه](تحلیل-اولیه.md): توصیف اصل فرضیه و شرایط منبع.
- [به‌روزرسانی مدرس](به‌روزرسانی-مدرس.md): یک رویداد تازه و تاریخ‌دار برای هر تغییر یا توضیح.
- [بازبینی مستقل](بازبینی-مستقل.md): فهم ساده و نقد مستقل؛ هر بار یک عکس لحظه‌ای.
- [ارزیابی نتیجه](ارزیابی-نتیجه.md): بررسی حرکت بازار با منبع و زمان مشخص.
- [گزارش دوره‌ای](گزارش-دوره‌ای.md): جمع‌بندی پس از شکل‌گرفتن داده کافی.

براکت‌ها و متن‌های راهنما فقط جای‌نگهدار هستند و نباید به‌عنوان داده واقعی تلقی شوند.
