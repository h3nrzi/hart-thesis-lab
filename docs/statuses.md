# واژه‌نامه وضعیت پرونده

| وضعیت | کاربرد |
|---|---|
| در انتظار تکمیل | پوشه ایجاد شده ولی سند اولیه هنوز کامل و تأیید نشده است. |
| در حال پیگیری | تحلیل اولیه مستند شده و بررسی ادامه دارد. |
| تحقق مشروط | بخشی از شروطِ از پیش گفته‌شده رخ داده اما نتیجه نهایی قطعی نیست. |
| نقض سناریو | شرط نقضِ از پیش ثبت‌شده به‌طور مستند اتفاق افتاده است. |
| پایان‌یافته | افق زمانی یا شرط پایان مشخص‌شده تمام شده و نتیجه ثبت شده است. |
| نامشخص | داده یا قواعد کافی برای داوری وجود ندارد. |

**هشدار:** وضعیت پرونده را با وضعیت معامله یکی نگیرید. «پایان‌یافته» به معنی سودده نیست.
