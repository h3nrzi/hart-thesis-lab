# معیارهای بررسی کیفیت تحلیل

| معیار | سؤال |
|---|---|
| وضوح سناریو | آیا جهت، منطق و افق زمانی در **متن ارسالی کاربر** روشن است؟ |
| شرط ابطال | آیا مدرس پیش از نتیجه، شرط نقض مشخص کرده؟ |
| سازگاری استدلال | شواهدِ گفته‌شده با فرضیات تناسب دارند؟ |
| آپدیت‌ها | آیا تغییر دیدگاه مدرس همراه با زمان و منبع ثبت شده؟ |
| ارزیابی نهایی مدرس | آیا خود مدرس نتیجه یا پایان سناریو را مستند بررسی کرده؟ |

`review-...md` برای نقد مستقل AI است؛ `update-...md` برای محتوای آپدیت مدرس؛ `outcome.md` فقط پس از اطلاعیه صریح مدرس درباره نتیجه یا پایان قابل ایجاد است. «نامشخص» امتیاز صفر یا شکست نیست. بدون سند واقعی معامله، ادعای نرخ برد و سود نمی‌کنیم. گزارش‌های دوره‌ای وضعیت‌های باز را جدا از پرونده‌های بسته‌شده نشان می‌دهند.
