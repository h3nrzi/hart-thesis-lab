# ماشین حالت مشتق‌شده از فایل‌های مخزن

وضعیت عملیاتی **ذخیره دوم ندارد**؛ از وجود/محتوای فایل‌های پرونده در آخرین HEAD محاسبه می‌شود. `case.md` و `INDEX.md` نمای انسانی‌اند و باید با وضعیت مشتق‌شده هماهنگ بمانند.

| مرحله فنی | شرط مستند | عمل مجاز |
|---|---|---|
| `AWAITING_LINK` | هیچ شناسه‌ای برای کار مشخص نیست | درخواست URL؛ بدون نوشتن |
| `AWAITING_ORIGINAL` | `case.md` هست، `original.md` نیست | فقط متن اولیه ارسالی کاربر |
| `TRACKING` | `original.md` هست، آپدیت اعلام نتیجه مدرس نیست | آپدیت از کاربر یا نقد مستقل |
| `READY_FOR_OUTCOME` | آپدیتِ واجد شرایط اظهار نتیجه مدرس هست، `outcome.md` نیست | ایجاد پیش‌نویس نتیجه مشروط |
| `DRAFT_OUTCOME` | `outcome.md` پیش‌نویس موجود | تکمیل با رجوع به همان آپدیت مدرس |
| `CLOSED` | `outcome.md` تکمیل و `case.md` بسته | فقط مطالعه؛ اصلاح با سند مستقل |
| `CONFLICT` | ساختار غیرمجاز، مدرک ناسازگار یا مرحله مبهم | توقف تمام ثبت‌های تحلیلی |

## رویدادهای ممنوع
- تحلیل اولیه بدون پیام استخراج کاربر.
- دو `original.md`، بازنویسی نسخه اولیه بعد از ثبت، دست‌کاری `update-*.md` موجود.
- ثبت نتیجه فقط بر پایه برداشت AI، نمودار قیمت، یا یک آپدیت مدرس بدون اعلام صریح پایان/نتیجه.
- معرفی تعداد لایک یا صحت جهت پیش‌بینی به‌عنوان سود واقعی.

## هویت و ترتیب
- شناسه پرونده از خود URL می‌آید، نه عنوان.
- نام رویداد `YYYYMMDDTHHMMSSZ` = زمان ثبت UTC؛ زمان انتشار منبع داخل رویداد مستقل است.
- اگر محتوایی قبلاً ثبت شده، **همان فایل را ارجاع بده** و فایل تکراری ایجاد نکن.
- هنگام تعارض بین پرونده و `INDEX.md`، پرونده مقدم است؛ به‌روزرسانی INDEX باید در همان PR انجام شود.

برای اجرا: `python3 scripts/agent_status.py --id <idea-id>`.
