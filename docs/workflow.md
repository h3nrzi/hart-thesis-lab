# راهنمای مرحله‌به‌مرحله

## مرحله ۱: فقط لینک
کاربر لینک ایده TradingView را می‌دهد؛ **همین و بس**. بدون استخراج متن/تصویر/آپدیت از صفحه، فقط شناسه و نشانه نماد URL ثبت می‌شود. بازار، تایم‌فریم و تحلیلگر را تنها اگر کاربر مشخص کرده باشد به دستور اضافه کنید:

```bash
python3 scripts/create_case.py --url "https://www.tradingview.com/chart/XAUUSD/DEMO1234-example/"
# اختیاری، فقط با داده ارائه‌شده توسط کاربر:
# --market "طلا" --timeframe "4H" --analyst "نام تحلیلگر"
```

پیوند بالا **نمونه ساختگی و غیرقابل استناد** است. خروجی فقط `analyses/DEMO1234/case.md` و ردیف `INDEX.md` است. `original.md` هنوز ساخته نمی‌شود.

## مرحله ۲: پیام بعدی و متن تحلیل اولیه
کاربر استخراجِ خودش از تحلیل مدرس را ارسال می‌کند. حالا از `templates/original.md`، یک `original.md` داخل پرونده می‌سازیم. اعداد و شروط فقط از متن رسیده، نه برداشت AI. وضعیت `case.md` به «در حال پیگیری» تغییر می‌کند.

## مرحله ۳: دریافت آپدیت یا تهیه نقد
به ازای **هر آپدیت که کاربر از مدرس می‌فرستد**، فایل `update-YYYYMMDDTHHMMSSZ.md` بسازید؛ به ازای هر تحلیل مستقل AI، فایل `review-YYYYMMDDTHHMMSSZ.md`. هر دو **در همان پوشه** هستند. از `templates/update.md` و `templates/review.md` استفاده کنید. اگر زمان انتشار مدرس معلوم نیست، «نامشخص» بگذارید. بررسی وضعیت بازار در نقد، پایان رسمی پرونده نیست.

## مرحله ۴: فقط در صورت بررسی صریح نتیجه توسط مدرس
پس از اینکه کاربر **آپدیت دارای اظهار صریح مدرس درباره نتیجه/پایان سناریو** را فرستاد، سند آپدیت با منبع معتبر، شاهد و مقدار «بررسی صریح نتیجه توسط مدرس: بله» ثبت می‌شود. آن‌گاه:

```bash
python3 scripts/prepare_outcome.py --id DEMO1234 --update update-20261103T160000Z.md
```

این دستور `outcome.md` را فقط به شکل **پیش‌نویس** می‌سازد؛ آن را خودکار پر یا نهایی نمی‌کند. نتیجه مدرس و ارزیابی مستقل را جدا وارد کنید. پس از تکمیل، «وضعیت ارزیابی» را «تکمیل‌شده»، «وضعیت پرونده» را «بسته‌شده» و ردیف `INDEX.md` را هم به‌روزرسانی کنید. بدون سند مدرس، هیچ `outcome.md` ایجاد نمی‌شود.

## مرحله ۵: گزارش‌های دوره‌ای
در `reports/` به کمک `templates/periodic-report.md` پرونده‌های بسته‌شده را جمع‌بندی کنید. پرونده‌های باز یا فاقد پیگیری نتیجه توسط مدرس را برد/باخت قطعی حساب نکنید.

ابزارهای موجود، متن TradingView یا آپدیت‌های آن را استخراج نمی‌کنند. `scripts/validate_structure.py` و GitHub Actions فقط ساختار و شروط خاتمه را کنترل می‌کنند.
