# الگوهای پرونده

- [case.md](case.md): شناسنامه خام؛ **فقط این فایل پس از ارسال لینک ساخته می‌شود**.
- [original.md](original.md): بعد از دریافت متن تحلیل اولیه از کاربر.
- [update.md](update.md): بعد از دریافت هر آپدیت مدرس از کاربر، با نام `update-...md` در همان پوشه.
- [review.md](review.md): نقد مستقل AI، با نام `review-...md` در همان پوشه.
- [outcome.md](outcome.md): فقط پس از آپدیت مستند مدرس که به‌طور صریح نتیجه/پایان را بررسی کرده است.
- [periodic-report.md](periodic-report.md): گزارش دوره‌ای با تفکیک پرونده‌های باز و بسته.

مقادیر داخل کروشه جای‌نگهدارند؛ داده واقعی محسوب نمی‌شوند.
