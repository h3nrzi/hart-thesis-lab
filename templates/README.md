# الگوهای آماده

برای هر ایده، نسخه‌ای مستقل از الگوهای زیر تهیه می‌شود:

- [تحلیل اولیه](original.md): توصیف اصل فرضیه و شرایط منبع.
- [به‌روزرسانی مدرس](update.md): یک رویداد تازه و تاریخ‌دار برای هر تغییر یا توضیح.
- [بازبینی مستقل](review.md): فهم ساده و نقد مستقل؛ هر بار یک عکس لحظه‌ای.
- [ارزیابی نتیجه](outcome.md): بررسی حرکت بازار با منبع و زمان مشخص.
- [گزارش دوره‌ای](periodic-report.md): جمع‌بندی پس از شکل‌گرفتن داده کافی.

براکت‌ها و متن‌های راهنما فقط جای‌نگهدار هستند و نباید به‌عنوان داده واقعی تلقی شوند.
