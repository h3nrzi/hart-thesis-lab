# پرونده‌های تحلیل

فعلاً **هیچ پرونده تحلیلی ساخته نشده است**.

در آینده، هر پوشه با **شناسه یکتای ایده تریدینگ‌ویو** نام‌گذاری می‌شود:

```text
analyses/
  <idea-id>/
    original.md
    updates/
      YYYYMMDDTHHMMSSZ.md
    reviews/
      YYYYMMDDTHHMMSSZ.md
    evaluations/
      YYYYMMDDTHHMMSSZ.md
```

نام پوشه نمونه صرفاً طرح ساختار است و پرونده واقعی محسوب نمی‌شود. هر رویداد یک فایل تاریخ‌دار مجزا است. ابتدا [قواعد مستندسازی](../CONTRIBUTING.md) را بخوانید.
