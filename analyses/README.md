# ساختار پرونده‌های مستقل

هنوز هیچ پرونده واقعی ایجاد نشده است. به‌ازای هر ایده یک پوشه داریم؛ **هیچ پوشه تو در تو برای update و review ایجاد نمی‌شود**.

```text
analyses/
  <idea-id>/
    case.md                      # تنها فایل هنگام ارسال لینک
    original.md                  # بعد از پیام دوم کاربر
    update-YYYYMMDDTHHMMSSZ.md  # آپدیت مدرس، ارسالی کاربر
    review-YYYYMMDDTHHMMSSZ.md  # بررسی مستقل AI
    outcome.md                   # فقط پس از بررسی صریح نتیجه توسط مدرس
```

برای ترتیب و شروط به [راهنمای جریان](../docs/workflow.md) مراجعه کنید. نام زمانی فایل، زمان ثبت UTC را نشان می‌دهد.
