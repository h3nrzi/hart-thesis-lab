# پرونده‌های تحلیل

فعلاً **هیچ پرونده تحلیلی ساخته نشده است**.

در آینده، هر پوشه با **شناسه یکتای ایده تریدینگ‌ویو** نام‌گذاری می‌شود:

```text
تحلیل‌ها/
  <شناسه-ایده>/
    تحلیل-اولیه.md
    به‌روزرسانی‌ها/
      YYYYMMDDTHHMMSSZ.md
    برداشت‌ها/
      YYYYMMDDTHHMMSSZ.md
    ارزیابی‌ها/
      YYYYMMDDTHHMMSSZ.md
```

نام پوشه نمونه صرفاً طرح ساختار است و پرونده واقعی محسوب نمی‌شود. هر رویداد یک فایل تاریخ‌دار مجزا است. ابتدا [قواعد مستندسازی](../قواعد-مستندسازی.md) را بخوانید.
